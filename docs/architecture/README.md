# Architektur

Hier werden Systemübersichten und Architecture Decision Records (ADRs) gesammelt.

Grundprinzipien:
- Plugins voneinander isolieren und separat versionieren.
- Zugangsdaten nie im Repository ablegen.
- Änderungen zuerst automatisiert prüfen.
- JTL-Version, PHP-Version und Plugin-Kompatibilität je Projekt dokumentieren.
