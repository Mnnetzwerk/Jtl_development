# Mitarbeit und Entwicklungsablauf

1. Für Änderungen einen Feature-Branch anlegen.
2. Zielversion von JTL-Shop und PHP im jeweiligen Plugin dokumentieren.
3. Tests und nachvollziehbare Reproduktionsschritte ergänzen.
4. Pull Request gegen `main` erstellen.
5. Keine Zugangsdaten, Kundendaten oder Shop-Dumps einchecken.

Hinweis: Branch-Schutz und erforderliche Reviews sind separat in GitHub zu konfigurieren.
