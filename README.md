# JTL Entwicklung

Modulares Repository für JTL-Shop-Plugins, Integrationen, Vorlagen und Entwicklungstools.

## Struktur

- `plugins/`: JTL-Shop-Plugins, jeweils in eigenem Unterverzeichnis
- `integrations/`: Schnittstellen und Anbindungen
- `templates/`: Wiederverwendbare Vorlagen
- `scripts/`: Entwicklungs- und Wartungsskripte
- `tests/`: Automatisierte Prüfungen
- `docs/architecture/`: Architekturentscheidungen
- `docs/jtl-api/`: API-Notizen und Integrationsdokumentation
- `.github/workflows/`: CI-Workflows

Die konkrete JTL-Shop-Version ist noch festzulegen. Dieses Grundgerüst enthält bewusst keine unbestätigten JTL-spezifischen Implementierungen.
